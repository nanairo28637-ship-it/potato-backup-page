Privacy Policy — potato-backup

Last updated: October 22, 2026

What this app accesses

potato-backup uses the Google Drive API via the rclone tool with the following scope:

  • https://www.googleapis.com/auth/drive — read/write access to the owner's own Google Drive.

What data is stored

Only the owner's own files (backup snapshots) are written to the owner's own Drive, in a folder named potato-otak/. No data is read from other users, no data is uploaded elsewhere, and no data is sold or shared with any third party.

Who has access

Only the application owner (the Google account that granted access). This is a personal, single-user application.

Data retention & deletion

Backup files remain in the owner's Drive until the owner deletes them your own. Removing the app's access via Google security permissions revokes all access immediately.
